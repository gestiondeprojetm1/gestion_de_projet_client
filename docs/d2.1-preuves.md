# D2.1 — État des preuves

Ce fichier distingue les éléments préparés localement des contributions réellement visibles dans Git. Il ne remplace pas les commits et Pull Requests des membres.

## Découpage

Le découpage à six tâches est décrit dans `docs/d2.1-decoupage.md`. Les branches proposées, fichiers, dépendances et critères de validation y sont indiqués.

## Contributions actuellement observables

Au moment de la préparation de D2.1, l'historique local montre notamment :

- `feature/socle-api` : contribution du socle API, Docker et CI ;
- `main` : merge de la PR du socle et commits documentaires ;
- `feature/gestion-stock` : branche personnelle de l'auteur, avec les changements D2.1 encore non commités.

Les cinq autres branches de tâches ne sont pas des preuves de contribution tant que leurs auteurs n'ont pas créé les branches, réalisé les changements, poussé leurs commits et ouvert leurs Pull Requests. Aucun commit ne doit être créé à leur place.

## Preuves à compléter par chaque membre

Pour chaque tâche, conserver dans la Pull Request :

1. le nom de la branche conforme au tableau de découpage ;
2. au moins un commit réellement écrit par le membre ;
3. les fichiers modifiés et les tests associés ;
4. la relecture et l'approbation d'un autre membre.

La branche `feature/gestion-stock` respecte le nommage GitHub Flow, mais elle ne constitue pas encore à elle seule la preuve des six contributions.
